# Ilham Maulana Sulaeman — Portfolio

**https://imsulaeman.github.io**

Personal corner of the internet. I'm a student at Bina Nusantara University in Bandung, Indonesia — building tools I wish existed, reading deeply, and tending a second brain where ideas connect.

This site is where I put my projects, essays, and the books and ideas that have shaped how I think.

---

## What's here

- **Projects** — things I've built: Folio (offline study companion) and Second Brain (personal knowledge base)
- **Writings** — original essays on learning, building, finance, and thinking
- **What shapes me** — books and ideas I keep returning to

## Stack

- [Astro](https://astro.build) 6 — static output, zero JS by default
- TypeScript
- JetBrains Mono + Instrument Serif
- GitHub Pages via GitHub Actions

## Running locally

```sh
npm install
npm run dev       # localhost:4321
npm run build
```
